# Maestrio

Aplicación web para docentes: calificaciones, pase de lista, tareas, actividades y reportes por alumno y por salón.

> Proyecto en desarrollo, hecho para aprender. Todavía no es apto para datos reales de alumnos.

## Requisitos
- Python 3.12 o superior

## Cómo correrlo
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```
Abre http://127.0.0.1:5000
